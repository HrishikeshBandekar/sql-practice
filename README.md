# sql-practice
About This Repository

This repository documents my journey of learning and practicing SQL using Oracle SQL. It contains SQL concepts studied, hands-on exercises, and query solutions developed to strengthen my understanding of relational databases and data manipulation.


Topics Covered

SQL Fundamentals: SELECT, WHERE, DISTINCT, ORDER BY, and filtering records.

DDL and DML: CREATE, ALTER, DROP, INSERT, UPDATE, and DELETE.

Constraints: PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, and constraint management.

SQL Functions: String, numeric, date, and conversion functions.

Aggregate Functions: COUNT, SUM, AVG, MIN, and MAX.

Grouping and Filtering: GROUP BY and HAVING.

Joins: INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN.

Subqueries: Single-row, multiple-row, correlated subqueries, and EXISTS.

Conditional Logic: CASE expressions and NULL handling using NVL and NULLIF.

Analytical Functions: ROW_NUMBER, DENSE_RANK, and NTILE.

Advanced Query Practice: Finding duplicates, ranking records, identifying missing data, and solving business-related SQL problems.

Practical Projects and Exercises

1. Employee and Incentive Database

Practice queries using employee and incentive tables, including salary calculations, department-wise analysis, date functions, joins, subqueries, and incentive calculations.

2. Garage Management System

Solve real-world database questions involving customers, employees, vendors, spare parts, purchases, and vehicle servicing. Practice joins, aggregate functions, correlated subqueries, analytical functions, and business calculations.

3. Salespeople, Customers, and Orders

Practice SQL problems involving customer ratings, salesperson commissions, order analysis, city-wise comparisons, correlated subqueries, and aggregate calculations.

Learning Objectives

Develop strong SQL fundamentals.

Improve query-writing and problem-solving skills.

Understand relationships between tables and retrieve data using joins.

Practice solving business-oriented database problems.

Prepare for SQL technical interviews.
